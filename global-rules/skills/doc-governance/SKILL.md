# 文档治理

## 归属

- 文档跟随它描述的对象。子目录自身已有 `README.md` 或 `docs/` 时，模块文档放该子目录的 `docs/`，否则归顶层。
- 新增单篇放所属 `docs/` 根；同一主题已成体系或资源型内容才建子目录。
- `plans/`＝事前冻结的计划，`images/`、`design-mockups/`＝只放资源，`research/`＝一手信源调研报告；这四个名字在任一层 `docs/` 下语义一致，不得挪用。
- **禁止新建 `docs/specs/`**：已存在的目录不回溯删除，但不得新增文件。
- **禁止新建 `CONTEXT-MAP.md` 一类总索引**。**取消 ADR**：不新建 `docs/adr/`、`docs/decisions/` 或 ADR 文件。

## CONTEXT.md（术语表）

- **不放进 `docs/`**，与 `AGENTS.md` 同级——仓库级术语放仓库根，模块级术语放该模块根。
- 只放术语定义与被否掉的同义词；禁止放规格、任务清单、实现笔记。

## 内容边界

- `docs/` 承载「如何操作」的指南与迁移文档，以及「归属」一节定义的四类目录（`plans/`、`research/`、`images/`、`design-mockups/`）；除此之外的非操作性叙事不进 `docs/`。
- 禁止手抄 API 列表、配置目录、数据结构与枚举取值；指南只写「当前可用状态」，禁止历史变迁词（以前／现在／不再／曾经）。
- 禁止为文档设字数门禁或引入新的文档检查工具。

## 章节编号

- 标题不写序号：用 `## 生成与校验`，不写 `## 4. 生成与校验`；层级只由 `#` 数量表达。序号是排版记号、不是标识符——插入或删除一节才不必重排后面所有数字。
- **禁止在正文用数字指代章节**（`第 5 节`、`§2.1`、`见 3.2`）：改写成标题原文的引号引用（「见「生成与校验」一节」）。标题改名时检索该原文即可找齐引用；数字一旦被引用，插一节就等于改引用加全体重排。
- 有序列表不适用：渲染器会自动顺序编号，源文件里每级有序列表统一写 `1.`，增删条目无需改数字。
- 版本号、条目数、时间等度量里的数字不适用。
- 既有文档的存量数字标题不回溯清理，只对新增与改动到的文档生效。

## README.md 与 AGENTS.md 的边界（按读者分家，同一事实只写一处）

- **README 面向人**：产品是什么、怎么装、怎么用、怎么构建与测试、贡献流程（有 `CONTRIBUTING.md` 时只留指针）、发布与许可证。
- **AGENTS.md 面向 agent**：只写**每条任务都成立**的改动前必知（核心原则、硬门禁、验收命令、目录与归属判据、术语表指向）及**项目技能索引**；只在特定任务成立的细则下沉到 `<仓库>/.agents/skills/`（见 `~/.dsh/AGENTS.md`）。禁止复述 README 已写的安装、构建与用法步骤。
- 判据：读这句话的人是要「理解产品」还是「改对代码」？前者进 README，后者进 AGENTS.md 或项目技能。两处都写即为重复。
- 改 README 时同样适用：只补产品与用法，禁止把硬门禁与验收判据写进 README。

## 新增／更新／移动

- 新增：先搜同主题既有文档，有则就地更新，无则新建；禁止为同一主题新增第二份同语言文档。
- 更新：原地改写，禁止追加「更新于／变更记录／Changelog」段落（历史由 Git 承载）。
- 移动／重命名／删除：先检索引用并同步修改；引用未清不得动。删除事实类文档的前提是所述系统已不存在。
- 命名：新增文档用 `kebab-case.md`（资源目录内的 `README.md` 除外），既有 `snake_case` 不回溯改名。一个文档一种语言，禁止新增 `_CN`／`.zh` 译文副本。
- 外部工具目录豁免：第三方技能或工具自建自管的目录不迁移、不改名。

## 验收

- 用内置 `grep` 工具（或在 Git 仓库内用 `git grep`）检索旧路径或旧文件名，须无残留引用。
- 未新增 `_CN`／`.zh` 副本与 changelog 段落。
- 新增文档的 `docs/` 层级符合「归属」判据；未新增 `docs/specs/`、`CONTEXT-MAP.md`、`docs/adr/`、`docs/decisions/`。
- `AGENTS.md` 里没有 README 已写的安装／构建／用法步骤，也没有可下沉的特定任务细则；`README.md` 里没有「禁止／必须」类硬门禁与验收判据。
- 新增或改动过的文档：标题无序号；检索 `第 ?[0-9]+ ?节|§[0-9]` 须无输出（存量未改文档不在此列）。
